# Job OS: Fit Insight v3.1 stack

Following ADR 0005, Fit Insight (epic #127) is the post-v3.0 preference-shaped product. v3.1 ships three layers: a singleton **Hunt Profile** (structured targets/constraints plus optional Body), an always-on pure **Structural checklist** (compensation, seniority, role family, must-haves, deal-breakers → pass/fail/unknown), and an on-demand **Fit Insight** (structured summary, advantages, disadvantages, fit notes, gaps) produced via a Job OS facade method and a pluggable `FitAnalyser` port whose first adapter is an Amplify Function calling Amazon Bedrock — never browser-held model keys. At most one Fit Insight per Opportunity (latest run wins); mark stale when the Hunt Profile or Opportunity changes after `analysedAt`; analysing does not emit Decision Events. Analyse requires a usable Hunt Profile; model context is Hunt Profile + Opportunity + Employer (including Bodies) plus the structural checklist verdicts, without Decision Event history in v3.1. The analyser must not narrate checklist outcomes already visible on the form. It may use well-established public knowledge about a named employer when that changes the trade-off, preferring Employer record fields when present; live web enrichment (e.g. Tavily) remains out of scope. Also out of scope: learned ranking on Decision Events, and any guest-visible fit data.

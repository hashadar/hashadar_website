# Job OS: Fit Insight v3.1 stack

Following ADR 0005, Fit Insight (epic #127) is the post-v3.0 preference-shaped product. v3.1 ships three layers: a singleton **Hunt Profile** (structured targets/constraints plus optional Body), an always-on pure **Structural checklist** (compensation, seniority, role family, must-haves, deal-breakers → pass/fail/unknown), and an on-demand **Fit Insight** (structured summary, advantages, disadvantages, fit notes, gaps) produced via a Job OS facade method and a pluggable `FitAnalyser` port whose first adapter is an Amplify Function calling Amazon Bedrock — never browser-held model keys. At most one Fit Insight per Opportunity (latest run wins); mark stale when the Hunt Profile or Opportunity changes after `analysedAt`; analysing does not emit Decision Events. Analyse requires a usable Hunt Profile; model context is Hunt Profile + Opportunity + Employer (including Bodies), without Decision Event history in v3.1. Out of scope for this epic: Tavily-style employer enrichment, learned ranking on Decision Events, and any guest-visible fit data.

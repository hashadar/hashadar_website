# CFA Lab question content and screenshots live only in private, sign-in-only storage

The CFA Lab ([CONTEXT](../cfa/CONTEXT.md)) holds practice questions the Site Admin captures from screenshots of practice questions from their study materials. That content is not the Site Admin’s to publish, and this repository is public. This ADR records where it may and may not live.

- **Question content lives only in Amplify Data and a private bucket.** Stems, options, answers, explanations, LOS, Attempts, review state and Flags are Amplify Data models (`CfaQuestion`, `CfaAttempt`, `CfaReviewState`, `CfaFlag`) authorised for signed-in users only. Screenshots and assist results live in the `cfaScreenshots` Storage bucket with authenticated-only access; there is no guest or public path. Cognito stays admin-invite-only, so “signed in” means the Site Admin.
- **Nothing question-shaped goes in the repo.** No question text, screenshots, exports or fixtures made from real questions under `src/data`, `public/` or anywhere else. `src/data/pages/cfa.json` holds only Module and Reading names, exam weights, the exam date and UI copy; its validator rejects any other top-level key. Tests and demo data use made-up placeholder questions.
- **Source-neutral public text.** Code, comments, copy, docs, ADRs, test names, commits, pull requests and issues describe the input only as screenshots of practice questions from the Site Admin’s study materials. They never name where the material comes from. The Source field on a Question is free text the Site Admin types; it has no default in code.
- **Extraction stays inside the AWS account.** The browser uploads screenshots straight to the private bucket. An authenticated `startCfaAssist` mutation invokes the `cfa-assist` Lambda asynchronously; it reads the images from the bucket, calls Bedrock in the same account (the IAM grant Job OS already uses), and writes the JSON result to `assist/{jobId}.json`, which the Lab reads and deletes. No third-party model API and no keys in the browser.
- **Private Lab, not indexed.** Every `/labs/cfa` page is `noindex, nofollow` and the Lab is absent from the sitemap, like WMW and Job OS.
- **Deleting a Question deletes its screenshots**, review state and Flags. Attempts stay as anonymous history (Question id only).

Rejected: committing question JSON or screenshots (public repo); Site Content storage (guest-readable); a Next.js Server Action calling Bedrock (needs a hand-attached SSR compute-role policy and pushes multi-megabyte images through a request body limit); a synchronous resolver (vision calls can outlast the 30-second resolver timeout); per-device storage only (the Lab must sync between phone and laptop).

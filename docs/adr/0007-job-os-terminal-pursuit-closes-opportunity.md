# Terminal Application outcomes close the Opportunity

Opportunity status remains the listing lifecycle (`open`/`closed`), distinct from Application pursuit status. For a personal hunt ledger, leaving a pursuit in a terminal state (`accepted`, `rejected`, `withdrawn`) means the listing is done, so those transitions close the Opportunity. Pass still leaves the Opportunity open (owner may revisit). Moving an Application out of a terminal status does not reopen the Opportunity — the owner reopens the listing explicitly if needed.

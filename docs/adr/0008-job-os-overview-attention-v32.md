# Job OS v3.2: Overview as attention surface

v3.1 shipped Fit Insight. Epic [#169](https://github.com/hashadar/hashadar_website/issues/169). v3.2 is **Overview-only**: replace the stub landing page with a read-only **attention surface** of non-terminal Applications (`researching`, `applied`, `interviewing`, `offer`), each row showing Employer, Opportunity title, Application status, and Tracking note. Sort by pursuit urgency (`offer` → `interviewing` → `applied` → `researching`), then within a status by latest Decision Event for that Application (fallback: Opportunity `noticedAt`). Assembly lives on the Job OS facade as `listOverviewAttention()` — the UI does not join or sort. Page composition is heading, one-line description, list, and empty state (link to Opportunities); no KPI strip, Status map, secondary feeds, inline edits, or undecided bare Opportunities. Status map, employer discovery/enrichment, and other hunt improvements are explicit later work. Domain language: `CONTEXT.md` (Overview, Status map, sharpened `researching`).
